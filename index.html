01 / Perfil

Sobre Mim

Desenvolvedor Web com foco em criar experiências digitais que convertem. Especializado em landing pages de alta performance, sites institucionais e aplicações web modernas.


Minha stack principal: HTML5, CSS3, JavaScript (Vanilla/ES6+) e React. Trabalho com design mobile-first, acessibilidade (WCAG), performance (Core Web Vitals) e SEO técnico. Cada projeto é pensado para ser rápido, bonito e funcional.


Entregas recentes incluem: landing pages para clínicas, oficinas, academias e e-commerce de peças mobile; sites institucionais com identidade visual forte; e web apps com autenticação, banco de dados e tempo real via Supabase.
